Excel Optimization: Criteria, Boolean Logic & Matrix Operations

Read article ▾

Criteria play an essential role in Excel data processing. They involve concepts from discrete mathematics, Boolean algebra, algorithms, logical branching, and Venn diagrams. Understanding these concepts can simplify formulas, reduce redundant calculations, and improve processing efficiency.

1. Boolean Logic

Common Boolean operators are OR (A + B), AND (A × B), XOR (AB′ + A′B), and NOT (A′). In Excel arithmetic, OR can use addition (nonzero = TRUE), AND uses multiplication, and NOT uses 1-A for Boolean values.

2. Single and Multiple Criteria

=(A2:A20="Bottle")
=ISNUMBER(MATCH(A2:A20,{"Bottle","Box"},0))

3. Combining Criteria

AND uses multiplication; OR can use addition followed by a nonzero check.

=(A2:A20="Bottle")*(B2:B20="Active")
=((A2:A20="Bottle")+(A2:A20="Box"))>0

4. Matrix Operations

MMULT() performs matrix multiplication and can help aggregate criteria across multiple columns.

5. Key Principle

Efficient Excel formulas need not be the shortest. Readability, maintainability, reusability and computational efficiency matter.

Excel Optimization: Processing Data More Efficiently

Read article ▾

Large Excel workbooks become slow when formulas repeatedly process the same data. A practical improvement is reducing the records each formula evaluates.

1. The Problem

If multiple reports repeatedly calculate across a 200,000-row Masterlist, processing can be inefficient.

2. A Helper Sheet

Filter the source into a smaller working dataset before report calculations: for example, 200,000 source records to approximately 800 monthly records. Other report sheets reference the smaller subset.

3. Using FILTER()

=FILTER(A2:D200001,G2:G200001=J1)

This filters records using the selection in J1.

4. Key Principle

Efficient data processing is about removing unnecessary operations, not merely choosing faster functions.

5. Python Example

records = [10, 20, 30, 40, 50]
filtered = [value for value in records if value > 25]
print(filtered)
