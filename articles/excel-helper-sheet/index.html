Create a Helper Sheet: A Practical Excel Optimization Strategy

Use helper sheets and Power Query to stop thousands of reports from repeating the same calculation.

Website edition adapted from my technical writing and examples

One of the simplest ways to improve a large Excel reporting system is to split data preparation from report calculations.

The challenge

Thousands of formulas may repeatedly examine around 15,000 monthly records, even when each report needs only a subset. A source Masterlist may contain 200,000 rows, while a selected period needs only approximately 800.

Method 1 — FILTER and CHOOSE

A helper sheet extracts the required records and columns once. Other sheets then use the reduced output.

=FILTER(CHOOSE({1,2,3,4},ColA,ColB,ColD,ColF),ColG=SelectedDate)

The named ranges in this example represent columns from the source workbook.

Method 2 — Power Query M

For more structured processing, select only necessary columns with Table.SelectColumns(), filter with Table.SelectRows(), group records with Table.Group(), assign row numbers with Table.AddIndexColumn(), and expand, unpivot and pivot the result as required for your reporting layout.

Example workflow

Masterlist (200,000 rows) → helper dataset (~800 rows) → reports

When output tables and report references are designed carefully, one preparation step can replace a large amount of repeated work.

Takeaway

Process each relevant source record as few times as practical. A good helper sheet is a simple data-processing layer, not merely an extra worksheet.
