Excel Optimisation: Criteria, Boolean Logic, and Matrix Multiplication

Criteria play an essential role in Excel data processing. They involve concepts from discrete mathematics, Boolean algebra, algorithms, logical branching, and Venn diagrams. Understanding these concepts can significantly simplify formulas, reduce redundant calculations, and improve processing efficiency.

Criteria are commonly used in functions such as SUMPRODUCT() and FILTER(), where we need to identify records based on one or more conditions.

1. Boolean Logic

The most commonly used Boolean operators are:

  • OR: A + B
  • AND: A * B
  • XOR: AB′ + A′B
  • NOT: A′

In Excel arithmetic, OR uses addition (nonzero = TRUE), AND uses multiplication, and NOT uses 1-A, where A and B represent 1 (TRUE) or 0 (FALSE).

2. Single and Multiple Criteria

If you want to find a specific value within a column:

=(col="Bottle")

If you want to match multiple values from a list:

=ISNUMBER(MATCH(col,{"Bottle","Cap"},0))

This allows us to identify records matching any value in the predefined list.

3. Partial Text Matching

If you want to find text containing a specific keyword:

=ISNUMBER(SEARCH("Bottle",col))

For multiple keywords, we can combine SEARCH() with matrix multiplication:

=MMULT(--ISNUMBER(SEARCH({"Bottle","Cap"},col)),{1;1})>0

This checks whether each cell contains at least one of the specified keywords. Note that SEARCH() performs substring matching rather than full regular-expression matching.

4. Multiple Columns and Matrix Multiplication

When dealing with multiple columns, MMULT() can help simplify complex criteria by applying matrix multiplication.

For example, to find whether either column equals "Bottle":

=MMULT(--(C5:D10="Bottle"),{1;1})>0

To check whether column C equals "Bottle" or column D equals "Cap", respectively:

=MMULT(--(C5:D10={"Bottle","Cap"}),{1;1})>0

We can also combine MMULT() with functions such as CHOOSE() to dynamically select and restructure columns before applying our criteria. With the right approach, multiple logical conditions can be evaluated through a single matrix operation rather than writing repetitive expressions.

5. Creativity Beyond Conventional Formulas

Ultimately, optimisation requires more than simply knowing Excel functions. Achieving better readability, simplicity, and efficiency requires creativity, logical reasoning, experimentation, and the ability to recognise patterns, and sometimes a little luck.

Even large language models such as ChatGPT and DeepSeek may not always identify the simplest or most elegant solution immediately.

The best solution comes from questioning conventional approaches, exploring different possibilities, and discovering connections between concepts that may initially seem unrelated. Keep experimenting, keep challenging your own solutions, and never stop looking for better ways to solve problems.
