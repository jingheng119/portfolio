Excel Optimisation: Criteria, Boolean Logic & Matrix Operations

Apply Boolean logic, matching criteria and matrix multiplication to simplify Excel calculations.

Website edition adapted from my technical writing and examples

Criteria play an essential role in Excel data processing. Understanding Boolean algebra helps reduce complicated conditions into more readable and efficient formulas.

Boolean operators

For Boolean values of 0 and 1: AND corresponds to multiplication (A*B), NOT to 1-A, and OR can be expressed as (A+B)>0. XOR can be written as (A<>B).

Single and multiple criteria

=(A2:A20="Bottle")
=ISNUMBER(MATCH(A2:A20,{"Bottle","Box"},0))

Combining criteria

=(A2:A20="Bottle")*(B2:B20="Active")
=((A2:A20="Bottle")+(A2:A20="Box"))>0

Count matches across columns with MMULT

For a matrix of records in E2:F20, MMULT() can sum each row's matches against one value. For example, this returns a per-row match count for the value in J2:

=MMULT(--(E2:F20=J2),{1;1})

If a list of target values must be evaluated, the matrix dimensions and how duplicated matches are counted should be decided explicitly before combining the results.

Principle

Effective Excel formulas should be accurate, readable, reusable and efficient—not simply short.
